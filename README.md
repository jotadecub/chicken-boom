# Sistema de Ventas - Local de Comida

Sistema web para la gestión de ventas e inventario de un local de comida rápida (frituras de pollo, papas fritas, etc.), con panel administrativo y landing pública.

## Stack
- **Frontend:** React + TypeScript + Vite + Tailwind CSS
- **Backend:** Node.js + Express + TypeScript + Prisma
- **Base de datos:** PostgreSQL
